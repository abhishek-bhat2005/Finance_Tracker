# Finance Tracker

📌 Overview
A full-stack personal finance management application that helps users track income, expenses, budgets, and spending trends through a secure dashboard.

✨ Features
- User Authentication (JWT)
- Income Management
- Expense Tracking
- Budget Management
- Analytics Dashboard
- Responsive Design

🛠 Tech Stack
Frontend:
- React.js
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Authentication:
- JWT
- bcrypt
